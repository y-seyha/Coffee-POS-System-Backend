## 🚀 Getting Started
### 1. First, Clone the repository:
#### Clone Repo : git clone https://github.com/y-seyha/Coffee-POS-System-Backend.git
##### Navigate to project : cd Coffee-POS-System-Backend

### 2. Install dependencies:
```bash
npm install
```

### 3. 🔐 Environment Variables

Create .env file in the root directory: (.env) (**Environment variables are provided via Telegram (Yoeun Seyha)**).


### 4. Run the development server:
```bash
npm run start:dev
```

Open [http://localhost:3000/api/v1/health](http://localhost:3000/api/v1/health) with your browser to see the result.


### 5. 📄 API Documentation (Swagger)

Once the backend is running, open the Swagger UI:

👉 http://localhost:3000/swagger-documents

Swagger provides:
- 📌 All API endpoints
- 📌 Request & response structures
- 📌 Authentication testing (JWT)
- 📌 Interactive API testing
- 
### 6. Notes

- Make sure Node.js (v18+) is installed
- Ensure `.env` file is properly configured before running the project
- Backend runs on **port 3000 (required for API & CORS configuration)**
